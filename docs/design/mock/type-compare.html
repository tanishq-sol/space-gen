Recommendation: Hanken Grotesk 600

  • Measured at 40px/600 for "Living room, proposed layout": Hanken Grotesk 501px, system stack 512px, Instrument Sans 522px. Hanken sets the most compact title, so long room and project names wrap later on a phone, and it is the closest in width to the system face the rest of the UI uses.
  • The measurement label stays in the system face with tabular figures either way, so the display face never touches numbers.
  • It is a neutral face for a client-facing page about someone else's room: it does not add its own personality over the scan. Instrument Sans has the more distinctive letterforms, which would suit a landing page later but competes with the scan on a share page.
  • Cost: one extra font file, loaded only on two routes (self-host the 600 weight with font-display: swap; the fallback is the system stack, so there is no layout shift beyond a width tweak).
